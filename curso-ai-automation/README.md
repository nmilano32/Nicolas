# AI Automation

Carpeta de trabajo para el curso **AI Automation**.

## Estructura

- `notas/` — textos y apuntes que voy pegando durante el curso, organizados por clase/módulo o tema, para poder consultarlos después.
- `recursos/` — material de referencia: links, PDFs, documentación externa.
- `entregas/` — trabajos y entregas del curso.

## Flujo de trabajo

1. Pego el material o texto plano de una clase en `notas/` (por ejemplo `notas/01-introduccion.md`).
2. Hago consultas sobre ese contenido en el chat.
3. Cuando corresponde una entrega, armamos el archivo en `entregas/`.
